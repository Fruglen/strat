# Design With Superpowers ⚡

A Claude Code / Agent **skill** — a field guide for building cinematic,
award-winning landing pages and hero sections. Dark, video-driven, with buttery
text reveals and tactile micro-interactions.

It packages **14 reusable "superpowers"** (self-contained techniques),
**copy-paste component code** (React/TS + Framer Motion + CSS), and **8 complete
page recipes** you can clone wholesale.

## What's inside

| File | Contents |
|------|----------|
| [`SKILL.md`](SKILL.md) | The skill entry point — how to compose superpowers, the default stack, aesthetic principles, and the polish checklist. |
| [`references/techniques.md`](references/techniques.md) | The 14 superpowers, each with its mechanism, knobs, and gotchas. |

| [`references/recipes.md`](references/recipes.md) | 8 full build specs: Lithos, SynapseX, Prisma, VANGUARD, Jack 3D, Organic Visions, Velorah, Veldara. |

## The 14 superpowers

1. Cursor-spotlight reveal · 2. Mouse-scrubbed video · 3. Scroll-scrubbed video ·
4. Liquid glass / glassmorphism · 5. Scramble text · 6. Pull-up / staggered
reveal · 7. Scroll-linked char opacity · 8. Magnetic hover · 9. Sticky-stacking
cards · 10. Scroll-driven marquee · 11. Ken Burns zoom · 12. Particle field ·
13. Nav patterns · 14. Watermark display type.

## Default stack

React 18 + TypeScript + Vite + Tailwind CSS 3 + Framer Motion + lucide-react.
Single-page, no routing. Vanilla HTML + Canvas where there's no build step.

## Install as a skill

Drop the `design-with-superpowers/` folder into your skills directory
(e.g. `~/.claude/skills/`) so the agent can load it on demand. Trigger it with
prompts like *"design with superpowers"*, *"build a cinematic hero section"*,
or *"make me a premium landing page"*.
