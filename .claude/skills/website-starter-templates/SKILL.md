# Website starter templates

Copy a starter into a new folder, then redesign it. Never ship a starter's look unchanged.

| Folder | Stack | Best for | Source |
|---|---|---|---|
| `modern-landing-page/` | Plain HTML, CSS, vanilla JS, scroll animations, glass nav. No build step. | Single-page demos deployed straight to Cloudflare Pages | https://github.com/thearyanveid/Starter-modern-landing-page |
| `cafe-astro-tailwind/` | Astro + Tailwind | Cafe, bakery, catering and other food or local-business sites | https://github.com/minggo-commits/cafe-website-starter-kit |
| `astro-landing-shadcn/` | Astro + shadcn components, auth pages | Demos that need more than static pages | https://github.com/emamalias/astro-landing-starter |

Also worth browsing: HTML5 UP (https://html5up.net), free responsive HTML5 templates under
CC BY 3.0. They need attribution unless you buy a license.

Check each folder's LICENSE before reusing it commercially. The Astro starters need
`npm install` before `npm run dev` or `npm run build`.
